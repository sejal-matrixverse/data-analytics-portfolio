# BFSI Loan Portfolio Analytics

## Overview

BFSI Loan Portfolio Analytics is an end-to-end data analytics project that analyzes loan applications, customer profiles, regional performance, and portfolio risk using PostgreSQL and Power BI. The project demonstrates the complete analytics lifecycle from data preparation to executive dashboard reporting.

---

## Business Problem

Financial institutions require actionable insights into loan approvals, customer risk, portfolio performance, and regional operations to support data-driven decision-making. This project provides an interactive analytics solution for monitoring these key business areas.

## Key Insights

- Business loans represent the largest share of the portfolio.
- Approval rate is over 60%, while default rate remains low.
- East and West regions contribute the highest loan volumes.
- Customer credit score plays a significant role in loan approval.
- Regional and branch performance varies across the portfolio.
