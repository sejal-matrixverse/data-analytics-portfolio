# Power BI Dashboards

This folder contains the Power BI report developed for the BFSI Loan Portfolio Analytics project.

---

## Dashboard Pages

1. Executive Loan Portfolio
2. Loan Performance
3. Customer Insights
4. Risk Analysis
5. Regional Performance

---

## KPIs

- Total Applications
- Total Loan Amount
- Total Interest
- Approved Loans
- Pending Loans
- Rejected Loans
- Approval Rate
- Default Rate
- Average Loan
- Average Credit Score

---

## Filters

- Region
- Branch
- Loan Type
- Loan Status
- Employment Type
- Gender

---

## Features

- Interactive slicers
- Drill-down analysis
- Conditional formatting
- DAX measures
- Dynamic KPI cards
- Business insights

---

## Purpose

The dashboards provide management with a comprehensive view of loan portfolio performance, customer insights, risk monitoring, and regional operations.
