# Data Dictionary

| Column | Description |
|---------|-------------|
| customer_id | Unique customer identifier |
| loan_id | Unique loan identifier |
| application_date | Loan application date |
| loan_type | Type of loan applied for |
| loan_amount | Loan amount sanctioned |
| interest_rate | Interest rate applied |
| emi | Monthly EMI |
| annual_income | Annual customer income |
| credit_score | Customer credit score |
| credit_category | Credit risk classification |
| employment_type | Customer employment type |
| age | Customer age |
| gender | Customer gender |
| marital_status | Customer marital status |
| region | Customer region |
| branch | Branch handling the loan |
| loan_status | Approved, Pending or Rejected |
| approval_flag | Approval indicator |
| default_status | Default status |
| default_flag | Default indicator |
