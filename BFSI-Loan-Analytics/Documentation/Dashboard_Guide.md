# Dashboard Guide

This project contains five interactive Power BI dashboards.

---

# 1 Executive Loan Portfolio

Purpose

Provide an executive overview of the loan portfolio.

KPIs

- Total Applications
- Approved Loans
- Rejected Loans
- Pending Loans
- Total Loan Amount
- Total Interest
- Approval Rate
- Default Rate

Visuals

- Loan Type Analysis
- Loan Status Distribution
- Regional Portfolio
- Monthly Loan Trend

---

# 2 Loan Performance

Purpose

Analyze loan performance across different loan products.

Visuals

- Loan Type Performance
- Approval by Loan Type
- Interest Analysis
- Loan Amount Analysis
- Branch Performance

---

# 3 Customer Insights

Purpose

Analyze customer demographics and financial characteristics.

Visuals

- Gender Distribution
- Employment Analysis
- Credit Category
- Marital Status
- Age Distribution
- Income vs Loan Analysis

---

# 4 Risk Analysis

Purpose

Identify risky customers and default trends.

Visuals

- Default Analysis
- Credit Score Distribution
- Regional Defaults
- Loan Type Defaults
- Customer Risk Table

---

# 5 Regional Performance

Purpose

Evaluate branch and regional business performance.

Visuals

- Regional Portfolio
- Branch Performance
- Monthly Regional Trend
- Loan Type Portfolio
- Regional Summary Matrix
