# Dataset

This folder contains the dataset used in the BFSI Loan Portfolio Analytics project.

---

## Dataset

loan_portfolio.csv

---

## Description

The dataset contains loan application records including customer demographics, loan information, approval status, branch details, regional information, and financial attributes.

---

## Key Columns

- Customer ID
- Loan ID
- Loan Type
- Loan Amount
- Interest Rate
- Credit Score
- Employment Type
- Annual Income
- Region
- Branch
- Loan Status
- Default Status
- Application Date

---

## Usage

The dataset is imported into PostgreSQL for SQL analysis and then connected to Power BI for dashboard development.
