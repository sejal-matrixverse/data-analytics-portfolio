# Dataset

## Overview

This folder contains the loan portfolio dataset used for the BFSI Loan Analytics project.

The dataset includes customer demographics, loan details, approval status, default status, credit scores, income, and financial metrics required for loan portfolio analysis.

## File

- loan_data.csv

## Data Source

Portfolio dataset created for analytics practice.

## Usage

The dataset is imported into PostgreSQL and analysed using SQL before being connected to Power BI for interactive reporting.
